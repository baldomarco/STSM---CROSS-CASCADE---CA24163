# STSM---CROSS-CASCADE---CA24163
 Multi-temporal ALS-based initialization and validation of the iLand forest dynamics model under drought and bark beetle disturbances  

The script pipeline for this analysis is still under editing and development. It will be finalized based on the related article linked with the MSc. Marco Baldo's CA24163 Short Term Scientific Mission article: 

Baldo, M., Das, K.A., Kraszewski, B., Lisiewicz, M., Stereńczak, K., Merganič, J. & Merganičová, K. (in prep.). Multi-temporal ALS-based initialization and validation of the iLand forest dynamics model under drought and bark beetle disturbances.

The study area is the Białowieża National Park, Poland: https://en.wikipedia.org/wiki/Bia%C5%82owie%C5%BCa_National_Park

The institutions participating to this project are: IBL Forest Research Institute (https://www.ibles.pl/en/home-page/) which provided the source data. See the following publications:

https://academic.oup.com/forestry/article/98/5/726/8010266

https://www.sciencedirect.com/science/article/pii/S0303243420301665

https://zenodo.org/records/6559267

Czech University of Life Sciences Prague, Technical University of Zvolen and Slovack Academy of Sciences.

To use the code properly and cite them please contact the authors.
